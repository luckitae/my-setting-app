화면 구성

실제 단말 정보를 읽지 않는 설정 화면 모형입니다. 수치는 하나의 시간순 모의 기록에서 계산합니다. 현재 잔량은 원본의 76%로 유지합니다.

앱 이름

아이콘

앱 목록 아이콘은 배터리와 데이터 사용량 화면에 동시에 적용됩니다. 홈 화면 아이콘은 아래 PNG도 저장해 HTML과 같은 폴더에 두세요. 사진은 정사각형으로 가운데를 자릅니다.

기준일 갱신

1 = 평일, 0 = 휴일. 이전 기준일 다음 날부터 새 기준일까지 순서대로 입력하세요. 이미 지난 기록을 다시 무작위 생성하지 않습니다. 기준 시각은 16:03이며 실제 시계와 자동 동기화하지 않습니다.

파일로 보관

내보낸 index_new.html을 index.html로 바꾸어 사용하세요. 브라우저 저장이 차단되어도 HTML에 아이콘과 기준 기록을 함께 보관할 수 있습니다. 홈 화면 설치에는 app-icon.png와 manifest.webmanifest를 같은 위치에 두고 브라우저의 홈 화면 추가 기능을 사용하세요.

설정 제목을 길게 누르거나 주소에 ?edit=1을 붙이면 이 화면을 열 수 있습니다.
